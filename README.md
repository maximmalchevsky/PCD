# PCD - Unity Project

Unity 6 (6000.6.1f1) project containing coursework and tasks:

- **Task 3**: Interactive 3D transformations, shapes, and lighting.
- **Task 4-5**: City environment, first-person character controller (WASD + mouse look, jump, sprint), multi-camera system with camera switching (`C` key / UI buttons).
- **Task 6-7**: Full urban traffic and pedestrian simulation:
  - Multi-lane road network with right-hand traffic and dedicated turning routes.
  - Traffic light system with automated phase cycles and stop lines.
  - Car agents with forward obstacle scanning, collision avoidance, and pedestrian yielding.
  - Pedestrian routes with sidewalk navigation, zebra crossings, and dynamic meme characters (Shrek, Steve, Capybara, Among Us, Dropout Bear, Tung Tung).
  - Train system with animated bullet train and station platforms.

## Controls
- **WASD / Arrows**: Move player in First-Person mode.
- **Mouse**: Look around (click game view to lock cursor, `Esc` to unlock).
- **Space**: Jump.
- **Left Shift**: Sprint.
- **C**: Switch active camera view (First-Person, Intersection, City Overview, Train Station).

## Getting Started
Open the project in Unity 6000.6.1f1 or compatible version.
